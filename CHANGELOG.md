# 📦 Changelog

## [0.0.5] - 2026-04-05

### 🎉 Initial Release

First stable release of **qcf_quran_lite** — a lightweight, high-performance Quran rendering package for Flutter.

### ✨ Features

- 🕌 Full **offline Quran support** (604 pages - Madinah Mushaf)
- 🔤 Integrated **QCF (Hafs) font** for authentic rendering
- 📖 Dual reading modes:
    - PageView (real Mushaf layout)
    - Surah List (vertical reading)
- 🎯 Dynamic **Ayah highlighting system**
- 🔍 Fast **Arabic search engine** (diacritic-insensitive)
- 📊 Rich **metadata API**
- 🧩 Utility helpers (text, diacritics, glyphs)

### ⚡ Performance

- 🚀 60fps smooth scrolling
- 🧠 Optimized memory usage
- 📦 Lightweight (~10MB)

### 🎨 Customization

- Fully customizable UI components
